# CSE276 Artificial Intelligence Foundations — Project Mapping

This project is mapped to the six-unit CSE276 outline for Session 2026–27. Check the latest official LPU handout and faculty instructions before final submission.

| Unit | Syllabus coverage | Project implementation |
|---|---|---|
| I | AI foundations, history/evolution, AI types, AI vs ML vs DL vs Data Science, lifecycle, AI applications, problem formulation, state-space/search/solution space and performance measures | Unit I dashboard: comparison, lifecycle, formal graph problem and environment properties |
| II | BFS, DFS, Best-First, Hill Climbing, A*, heuristics, algorithm comparison, knowledge representation, semantic networks, frames, production systems/expert systems, propositional and predicate logic, Bayes theorem | Unit II: five search algorithms, semantic network, frames, production rules, logic examples and Naive Bayes |
| III | Intelligent agents, architecture, PEAS, rational agents, reflex/model-based/goal/utility/learning agents, autonomous and multi-agent systems, cooperation and human-AI collaboration | Unit III: PEAS table, four agent simulations, learning-agent concept and cooperative agents |
| IV | Symbolic/statistical AI, supervised/unsupervised/reinforcement learning, deep learning, foundation models, multimodal, agentic, edge and tiny AI | Unit IV: Decision Tree, K-Means, and conceptual comparison of the other paradigms |
| V | Generative AI, LLMs, prompt engineering, RAG, hallucination mitigation, explainability, fairness, transparency, privacy, security, governance and ethics | Unit V: prompt builder, local TF-IDF retrieval, explainability, group comparison and responsible-AI checklist |
| VI | Python AI ecosystem, TensorFlow, PyTorch, Hugging Face, Ollama, LangChain, vector databases, AI workflow, AGI and sustainable AI | Unit VI: ecosystem comparison, development workflow and future trends |

## Implemented versus conceptual
**Implemented:** BFS, DFS, Greedy Best-First, Hill Climbing, A*, semantic-network and frame representations, IF–THEN production rules, propositional/predicate examples, Naive Bayes, agent architecture simulations, cooperative multi-agent simulation, Decision Tree classification, K-Means clustering, local TF-IDF retrieval, prompt construction, group distribution and data-quality checks.

**Conceptual:** AI history, deep neural networks, reinforcement learning, foundation and multimodal models, LLM inference, vector databases, AGI and sustainable AI. These are explained without pretending the project trains or deploys them.

## Practical limitations
All patient-style records and labels are synthetic. Search paths represent an illustrative workflow. Machine-learning targets are synthetic categories. Metrics describe only a train/test split from this generated dataset and have no clinical meaning.
